
##How to Run the program
We created a virtual enviironment for our python python.
For Frontend we used  HTML,CSS and JavaScript
For Backend we used Flask and Python while using SQLite as a database

I would like you to install the following libraries with the specified version after creating the virtual environment 

Flask>=3.0
Flask-Session>=0.8
Flask-SocketIO>=5.3
simple-websocket>=1.0


## Setup (Python 3.9+)
```bash
python -m venv venv
venv\Scripts\activate
set SECRET_KEY=your-long-random-string      
python app.py
```
Open http://127.0.0.1:5000  in two browser such Incognito and Normal Browser
